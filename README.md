# Nearby

Nearby помогает взрослым детям, которые заботятся о пожилых родителях в США. Сервис отвечает на три вопроса: на какие государственные льготы может претендовать родитель, на сколько месяцев хватит его накоплений при разных видах ухода и как братья и сёстры делят расходы и помощь.

Регистрации и логина нет. Доступ к семье открывается по личной ссылке.

## Для кого

Взрослые примерно от 25 до 45 лет, которые управляют деньгами родителя, записывают его к врачам или помогают с повседневными делами. Часто это параллельно с работой и воспитанием детей, а опыта в таких вопросах обычно нет ни у кого в семье.

## Почему это важно сейчас

- **Население стареет.** По прогнозу Бюро переписи США, <a href="https://census.gov/library/stories/2018/03/graying-america.html">с 2030 года американцы старше 65 лет составят 21% населения</a>.
- **Спрос на помощь на дому растёт быстрее, чем кадры.** По оценке PHI, в уходе за людьми <a href="https://www.phinational.org/?p=22328">к 2034 году появится около 9,7 млн вакансий</a> с учётом ухода работников из профессии.
- **Уход во многом держится на мигрантах.** По данным Migration Policy Institute, <a href="https://www.migrationpolicy.org/article/immigrant-health-care-workers-united-states-2021">почти 40% домашних помощников в 2021 году родились за пределами США</a>. Изменения миграционной политики напрямую влияют на доступность и цену такого ухода.
- **Семья платит деньгами и временем.** Стоимость ухода высока, правила льгот сложные, а работа между братьями и сёстрами обычно распределена неравномерно.

## Возможности

1. **Проверка льгот.** Короткий опрос показывает, может ли родитель претендовать на федеральные и штатные программы: VA Aid and Attendance, Medicaid на долгосрочный уход, Medicare Savings Programs, налоговый вычет Dependent Care Credit. Опрос спрашивает о потребности в помощи с повседневными делами из-за потери памяти, о диагнозе деменции или болезни Альцгеймера и об инвалидности. Диагноз сам по себе не определяет результат: важнее, какая помощь нужна. Результат показывается как «возможно», «нужна проверка» или «скорее не подходит». Ответ «не знаю» даёт «нужна проверка», а не «скорее не подходит». Гарантий нет, а у каждой программы есть ссылка на официальный источник.
2. **Сценарии стоимости ухода.** Введите накопления и доход родителя, и увидите, на сколько месяцев их хватит при уходе дома, в assisted living и в доме с уходом в частной палате. Стандартные цены взяты из CareScout Cost of Care Survey 2025 и помечены как данные опроса или оценка. Любое значение можно изменить.
3. **Учёт взносов семьи.** Общие расходы делятся между братьями и сёстрами, часы помощи фиксируются отдельно, а баланс показывает, кто кому должен и какие переводы закроют долг. Видно и долю участия в заботе.

## Чем мы отличаемся от конкурентов? (самый вероятный конкурент: Aidaly)

Aidaly — приложение для родственников, которые ухаживают за близкими. По описанию в App Store, оно <a href="https://apps.apple.com/us/app/aidaly/id6502757047">даёт родственникам-сиделкам поддержку, обучение и оплату</a>, а в списке функций есть расчёт зарплаты и история выплат.

Nearby устроен иначе:
- мы не платим членам семьи и сиделкам и не считаем зарплату или почасовую оплату родственников;
- мы помогаем планировать: льготы, стоимость ухода и распределение обязанностей;
- мы не подбираем сиделок и дома, у нас нет чата и маркетплейса.

## Данные и источники

- Правила льгот хранятся как данные в `backend/app/eligibility/rules.json` с официальными источниками (va.gov, medicaid.gov, medicare.gov, irs.gov) и датой последней проверки.
- Стоимость ухода — оценки на основе национальных опросов. Они нужны для планирования и не заменяют местные цены.
- Все деньги хранятся в целых центах, без вычислений с плавающей точкой.

## Важно

Nearby даёт общую информацию для планирования. Это не юридическая, финансовая или налоговая консультация, и сервис не определяет, положена ли льгота. Перед решениями поговорите с консультантом по льготам, юристом по вопросам пожилых людей или налоговым специалистом.

## Запуск локально

Нужны Docker, Python 3.11 и Node.js 20 или новее.

```bash
docker compose up -d db

cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
uvicorn app.main:app --reload --port 8000

cd ../frontend
npm install
npm run dev
```

Приложение откроется на http://localhost:5173, документация API на http://localhost:8000/docs.

Тесты:

```bash
cd backend
pytest -q
```

## Переменные окружения

Файлы `.env` не коммитятся. Примеры есть в `backend/.env.example` и `frontend/.env.example`.

- `DATABASE_URL` — строка подключения к PostgreSQL
- `FRONTEND_ORIGINS` — разрешённые адреса фронтенда через запятую
- `VITE_API_URL` — адрес backend для фронтенда
