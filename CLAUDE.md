# Nearby

Веб-приложение для взрослых детей, которые помогают пожилым родителям. Три обязательные функции:

1. **Скрининг льгот.** Опрос (статус ветерана, доход, активы, штат, состояние родителя) и список программ, на которые родитель может претендовать. Результат с пометкой «возможно» и ссылкой на первичный источник. Правила хранятся как данные с источником и датой проверки.
2. **Калькулятор сценариев.** Сколько месяцев продлятся накопления родителя при уходе дома, в assisted living, в доме с памятью, в доме с уходом. Значения по умолчанию из CareScout, пользователь может менять.
3. **Учёт взносов семьи.** Несколько участников, расходы с делением, часы помощи родителю, баланс и переводы, доля нагрузки.

## Стек
- Backend: FastAPI, SQLAlchemy, PostgreSQL (порт 5433 в docker compose), Python 3.11, папка backend/
- Frontend: React + Vite, папка frontend/
- Запуск: docker compose up -d db, затем uvicorn из backend/

## Правила
- Деньги только в центах (целые числа), никаких float для денег.
- Логина и регистрации нет. Доступ к семье по share_token.
- Не коммить .env, ключи, личные данные.
- Суммы льгот брать только с официальных источников (va.gov, cms.gov, medicaid.gov, irs.gov, state gov). Агрегаторы не использовать как источник.
- Стоимость ухода по умолчанию для калькулятора сценариев брать из CareScout, с указанием года данных и ссылки.
- Ответы про льготы всегда «возможно», без гарантий.

## Что не делать
- Почасовые ставки, оплату сиделкам или членам семьи, расчёт зарплаты.
- Подбор сиделок и домов, маркетплейс, чат.
- Регистрацию и аккаунты.
- Функции вне трёх обязательных, пока не закончены эти три.
